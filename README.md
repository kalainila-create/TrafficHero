# TrafficHero 🚗

TrafficHero is a web-based road safety game developed using ASP.NET Web Forms and C#.

## 🎮 Features

- User Registration and Login
- Road safety gameplay
- Traffic signal scenarios
- Score and lives system
- Level progression
- Pedestrian safety scenario
- Ambulance priority scenario
- Traffic violation detection

## 🛠️ Technologies Used

- ASP.NET Web Forms
- C#
- HTML
- CSS
- JavaScript
- SQL Server

## 📁 Project Structure

- `Login.aspx` - User login
- `Register.aspx` - User registration
- `Game.aspx` - Main game
- `Rules.aspx` - Game rules
- `App_Code` - Backend/helper code
- `Images` - Game images
- `Scripts` - JavaScript files
- `Styles` - CSS files

## 🗄️ Database

The project uses SQL Server with a database named:

`TrafficHeroDB`

The connection string can be configured in `Web.config`.
